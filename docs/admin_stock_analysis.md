# 관리자 종목 검색 분석

**AI Brain → 차트 유사 사례**(`/dashboard/ai-bain/chart-predict`)의 **에이전트 매매 제안 → 관리자 전용 종목 검색 분석**에서 종목명, 초성 또는 6자리 코드를 검색하고 정확한 종목을 선택한 뒤 **분석 실행**을 누릅니다. 현재 자동 선정된 3종목 이외의 종목도 개별 분석합니다. 관리자 계정에만 이 영역이 표시됩니다.

검색 결과는 별도의 `adminCode` URL 매개변수로 복원합니다. 공용 차트의 `code`와 자동 선정 3종목을 바꾸지 않습니다. 기존 `/admin/stock-analysis?code=196170` 링크는 같은 종목이 선택된 차트 페이지의 관리자 영역으로 연결합니다.

결과의 **제안 비중 / 참고 진입 / 참고 손절 / 참고 목표**를 먼저 확인합니다. 참고 진입은 마지막 확정 일봉 종가이며, 실제 다음 장 시가를 확인한 뒤 손절·목표·비중을 다시 계산해야 합니다. 참고 가격을 주문 가격으로 사용하지 않습니다.

## 기존 에이전트와 같은 계산

- 추세 지속·거래량 동반 돌파·과매도 회복의 현재 진입 조건을 검사합니다.
- 공통 거래일 달력에서 최근 1,260거래일을 형성 1,008일과 최근 확인 252일로 나눕니다. 형성 기간의 비용 스트레스 순손익으로 조건을 선택하고 최근 확인 기간은 통과 여부만 판정합니다.
- 충분한 완료 거래와 두 기간의 양수 순손익·비용 2배 스트레스 조건을 통과한 경우 기존 매수 의견 표시 규칙을 적용합니다.
- ATR14 기준 손절 거리 = min(2 × ATR, 진입가 × 8%). 참고 손절 = 진입가 − 거리, 참고 목표 = 진입가 + 2 × 거리. 최대 보유 계획은 10거래일입니다.
- 과거 순손익으로 산출한 켈리의 1/4에 단일 종목 5% 상한과 계획 계좌 손실 1% 상한을 적용합니다. 이는 현재 에이전트 매매 제안과 동일한 정책입니다.
- 근거·품질·거래일·유효기간이 부족하면 제안 비중은 0%입니다. 가격 자료가 유효하면 참고 가격은 계속 확인할 수 있습니다. 부족한 승률·켈리 값을 채워 넣지 않습니다.

## 실행과 자료

검증된 기존 가격·품질 자료를 우선 사용하고, 자료 범위 밖의 종목은 해당 종목만 수집합니다. 수집 방식, 입력 거래일, 수집 시각, 재무 품질, 근거 진단 및 유효기간을 화면에서 확인합니다. 공급자 가격 보정·과거 공시 시점 미인증 등 기존 자료 한계도 표시합니다.

결과 조회와 화면 새로고침은 저장 결과만 읽습니다. 실행 중 또는 실패한 갱신에서 이전 매수 의견을 현재 의견으로 보여주지 않습니다. 동일한 자료의 반복 분석으로 기존 제안 기간을 연장하지 않습니다.

검색·분석 실행·결과 조회는 서버에서도 관리자만 허용합니다. 수동 검색 결과는 `data/admin_mirofish/symbol_alpha/`에 별도로 저장하며 자동 3종목 선정, 공용 성과 기록 및 자동 주문에 반영하지 않습니다.
