# 시총 상위 우량주 연구자료 확보

기존 가격 캐시의 **800일 제한은 공급원이 제공하는 전체 이력의 한계가 아니었습니다.** 날짜 범위 조회로 더 긴 일봉을 받을 수 있고, 일별 과거 시총은 연도별 Parquet, 과거 재무는 OpenDART 보고기간별 API와 접수번호 원문으로 확보할 수 있습니다. 외부 AI 모델이나 새 유료 계정 없이 현재 프로젝트에서 확인한 경로입니다.

연구 대상은 `data/kelly_research/large_cap_20261001_v2/report.json`의 고정 TOP100입니다. 우량주 조건에서 탈락한 종목 대신 101위 이하를 넣지 않습니다. 전체 시장 파일은 과거 시총 순위를 확인하는 원자료이며, 가격 수집·신호 분석 범위를 전종목으로 확대하지 않습니다.

자료 대조 중 기존 순위의 `KOSDAQ GLOBAL` 제외 오류를 발견했습니다. [KRX의 코스닥 글로벌 세그먼트](https://kosdaqglobal.krx.co.kr/)를 KOSDAQ으로 정규화하면서 원래 시장명을 보존하도록 수정했습니다. 알테오젠·에코프로·에코프로비엠·주성엔지니어링·원익IPS·리노공업·심텍이 실제 TOP100에 포함되고, 기존 목록의 하위 7개가 빠졌습니다. 재무 조건 통과는 50개에서 52개로 바뀌었습니다. 이전 결과를 덮어쓰지 않고 `v2`로 구분했습니다. 매수 조건이나 승률 기준을 완화한 변경이 아닙니다.

## 자료별 확보 경로와 검증 범위

| 자료 | 실제 확보 경로 | 사용할 때 지켜야 할 기준 |
|---|---|---|
| 장기 일별 가격·거래량 | NAVER `siseJson.naver` 날짜 범위 조회 | 원본 숫자와 수집시각 보존. 조정주가·배당·공시 당시 버전 검증 없이 과거 실행 가능 자료라고 표현하지 않음 |
| 과거 일별 시총·발행주식 수 | [FinanceData/marcap](https://github.com/FinanceData/marcap)의 연도별 Parquet | 실제 금액을 `Close × Stocks`와 대조. 문서의 단위 설명만 보고 백만원을 곱하지 않음 |
| 보고기간별 과거 재무 | [OpenDART 다중회사 주요계정](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019017) | 연결/별도·접수번호·통화·기간·누적 손익을 보존. 현재 조회한 정정 수치를 과거 최초 공시 수치라고 단정하지 않음 |
| 최초/정정 공시 원문 | [공시 검색](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001), [원문 ZIP](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003), [XBRL](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS002&apiId=2019019) | 판단 시점 이전 공개된 정확한 접수번호의 원문으로 수치 확인. ZIP 다운로드 성공과 재무 수치 검증을 구분 |

2026-10-03 표본 수집에서 삼성전자 일봉은 1990-01-03부터 9,481행, SK하이닉스는 1996-12-26부터 7,428행을 확보했습니다. 최근 3,000행은 fchart 응답과 일치했습니다. fchart는 6,000행을 요청해도 실제 3,000행만 반환했으므로 요청값만으로 날짜 범위를 보증하지 않습니다. [FinanceDataReader의 구현](https://github.com/FinanceData/FinanceDataReader/blob/master/src/FinanceDataReader/naver/data.py)도 fchart를 사용합니다.

NAVER 응답은 작은따옴표 헤더와 6/7열이 섞인 배열입니다. 안전한 리터럴 파싱과 인코딩 확인이 필요합니다. 거래정지의 시가·고가·저가·거래량 0행과 일부 OHLC 모순을 실제로 관측했습니다. 임의 숫자 보정이나 행 삭제로 자료를 완전하게 만들지 않습니다. 원본을 보존하고 분석 가능 여부를 별도로 판단합니다.

2015년 삼성전자 시총 자료의 종가는 1,330,000원, 가격 API의 같은 날 종가는 26,600원이었습니다. 시총 원자료는 당시 비조정 가격이고 가격 API에는 액면분할 조정 흔적이 있습니다. 시총은 원자료의 `Close × Stocks`로 확인하며, 서로 다른 가격 기준을 곱해 계산하지 않습니다. 한 종목의 분할 경계 확인으로 모든 기업행동 조정 방식을 검증했다고 주장하지 않습니다.

OpenDART는 공식 지원 시작연도와 실제 커버리지가 다를 수 있습니다. 표본에서 2015년 반기는 자료 없음(`013`), 2015년 사업보고서는 삼성전자와 SK하이닉스 모두 반환했습니다. 보고기간 종료일은 공개일이 아닙니다. 접수일 다음 날은 공개 시각을 모를 때의 보수적 대리 날짜이며, 최초 공시 수치임을 증명하지 않습니다.

## 수집 도구

Python 가상환경과 기존 프로젝트 의존성을 사용합니다. Parquet 수집에만 추가 패키지가 필요합니다.

```powershell
C:/bitman_marketfloww/.venv/Scripts/python.exe -m pip install -r requirements-research.txt
```

수집 결과는 `data/kelly_research/long_history_20261002/` 아래에 저장합니다. 생성 데이터는 Git에서 제외합니다. 수집기는 명시적인 외부 조회 옵션과 고정 대상·기간을 사용하고, 완료된 원본은 요청 식별자와 SHA-256을 확인하여 재사용합니다. 이후 단계가 실패해도 이미 받은 자료를 처음부터 다시 받지 않습니다.

확정된 대상의 장기 가격을 수집하는 명령:

```powershell
python scripts/collect_large_cap_price_history.py --universe-report data/kelly_research/large_cap_20261001_v2/report.json --start 2005-01-01 --end 2026-10-02 --output-dir data/kelly_research/long_history_20261002/prices --fetch
```

일별 과거 시총을 확보하는 명령:

```powershell
python scripts/collect_large_cap_market_caps.py --universe-report data/kelly_research/large_cap_20261001_v2/report.json --years 2015 2016 2017 2018 2019 2020 2021 2022 2023 2024 2025 2026 --out data/kelly_research/long_history_20261002/market_caps --fetch
```

보고기간별 재무와 소수 접수번호 원문을 확보하는 명령:

```powershell
python scripts/collect_large_cap_dart_history.py --cohort-report data/kelly_research/large_cap_20261001_v2/report.json --start-year 2015 --through-year 2026 --through-report 11012 --max-calls 92 --reuse-cache data/kelly_research/large_cap_20261001_v2/sources --env-file C:/bitman_marketfloww/.env --corp-codes C:/bitman_marketfloww/data/dart_corp_codes.json --out data/kelly_research/long_history_20261002/financials --fetch --original-samples
```

동일 명령에서 `--fetch`를 빼면 이미 완료된 원본만 재사용합니다. 누락된 요청은 보류하며 외부 호출을 하지 않습니다. 처음 수집할 때 사용한 대상·기간과 다른 실험은 새 출력 폴더로 구분하세요. DART 기간별 호출과 원문 표본 호출은 저장된 요청 원장에서 각각 예산을 제한하며, 실패·중단된 시도도 사용량으로 남깁니다.

가격 수집은 동시 요청 최대 3개, 재시도 횟수와 응답 크기를 제한합니다. 시총은 저장소 전체 복제 대신 필요한 연도 파일만 받습니다. DART는 50개 회사씩 순차 조회하며 2015–2025년 네 보고서와 2026년 1분기·반기, 총 46기간의 최대 92배치를 수집합니다. 이미 보관한 응답은 원래 수집시각을 유지합니다. 원문 표본 요청은 별도 예산 안에서 수행합니다. 키는 같은 프로젝트 `.env`에서 실행 중에만 읽고 출력·원본 메타데이터·오류 URL에 저장하지 않습니다.

## 실제 확보 결과

2026-10-03 수집 결과이며 전부 위 `v2` TOP100을 사용합니다.

| 자료 | 실제 확보량 | 범위·출력 |
|---|---:|---|
| 일봉 OHLCV | 100/100 종목, 421,295행 | 2005년부터 요청, 최신 2026-10-02. `prices/report.json`, `prices/prices.csv` |
| 종목별 가격 이력 길이 | 최소 406 · 중앙값 5,366 · 최대 5,366일 | 800일 초과 96종목, 3,000일 이상 73종목. 상장 전 이력은 채우지 않음 |
| 해당 TOP100 과거 시총 | 257,576행 | 2015–2026, `market_caps/current_top100_caps_<year>.csv` |
| 역사적 시총 상위 목록 | 2,883일 × 100개 = 288,300행 | KOSPI/KOSDAQ 시총으로 재순위. 우량주·보통주·거래 가능 상태 검증과는 별개 |
| 시총 원자료 무결성·단위 | 12파일, 259,470,546바이트 | 원자료 7,242,973행의 `Marcap = Close × Stocks` 대조 불일치 0 |
| 과거 주요 재무계정 | 46기간 · 92배치 · 6,880 레코드 | 신규 조회 90회 + 완료된 반기 배치 2개 재사용. `financials/collection_report.json`, `financials/financials.json` |
| 재무 레코드의 필수계정·기간 확인 | 6,768 레코드 통과 · 112개 계정 누락 | 연결 3,399 · 별도 3,481을 따로 보존. 보고기간 미확인 레코드 0 |
| 접수번호별 XBRL 표본 | 삼성전자·SK하이닉스 2015 사업보고서 각 1개 | ZIP 무결성 확인. 연결·별도 주요계정 16개를 API 수치와 대조해 16개 일치 |

가격의 품질 이상 표시가 있는 행은 4,801행, 53종목입니다. OHLC 범위 불일치 3,729행, OHL 0인 행 604개, 거래량 0인 행 1,071개이며 일부는 겹칩니다. 원본 숫자와 행을 바꾸지 않았습니다. 이 집계는 수집 도구가 반환하는 품질 표시이며 해당 원자료를 모두 유효 체결 가격으로 사용할 수 있다는 뜻은 아닙니다.

재무의 자료 없음(`013`) 배치는 6개입니다. 반환된 레코드가 없는 종목·보고기간 조합은 1,119개이며 상장 시점·실제 공시 커버리지·필수 항목 누락을 결과에서 구분합니다. `research_usable`은 계정·통화·기간의 수집 계약을 통과했다는 뜻으로, 과거 최초 공시 수치 검증이나 우량주 조건 통과를 뜻하지 않습니다.

XBRL 표본 대조는 자본·부채·영업이익·순이익의 정확한 2015년 기간과 KRW 단위, 연결/별도를 확인했습니다. 숫자 대조 근거는 `financials/xbrl_numeric_spot_check.json`입니다. 해당 접수번호가 최초인지 정정본인지의 전체 공시 이력은 아직 대조하지 않았으므로 다른 재무 레코드를 검증 완료로 승격하지 않습니다. 같은 접수번호의 `document.xml` 표본 두 건은 원문 ZIP 검증을 완료하지 못했으며 실패 SHA와 상태를 보존했습니다. 이 실패를 XBRL 수집 실패로 표현하거나 원인 미확인 상태에서 추가 호출을 반복하지 않습니다.

## 백테스트 투입 전 남은 검증

- 장기 가격의 기업행동 조정 기준을 종목별로 확인하고, 거래정지·OHLC 모순이 포함된 분석 구간을 처리해야 합니다. 현재 원자료의 `analysis_ready=false`는 수집 실패라는 뜻이 아니라 이 검증을 완료하지 않았다는 뜻입니다.
- 보고기간별 API 수치와 해당 접수번호 원문을 대조해야 합니다. 당시 공개된 최신 버전을 선택하고 이후 정정 수치나 비교연도 수치를 과거로 소급하지 않습니다.
- 현재 TOP100의 과거 자료는 생존 기업 코호트입니다. 과거 시총을 확보했더라도 당시 TOP100의 편입·탈락·상폐 자료까지 검증하지 않으면 생존편향 제거를 주장할 수 없습니다.
- 늘어난 이력으로 학습·검증 기간의 표본 수를 다시 계산해야 합니다. 기존 800일, 60/20/20 분할, 5일 보유 구조의 검증 구간은 160일이며 비중복 표본이 최대 26개여서 기본 30개 기준을 만족할 수 없었습니다. 긴 기간은 이 구조적 제약을 줄이지만, 실제 2σ 신호가 충분히 발생하거나 승률이 60%를 넘는다는 보장은 아닙니다.

이 단계는 **확보 가능한 자료와 재현 가능한 수집 경로**를 만드는 작업입니다. 자료 획득, 과거 시점 검증, 종목 자격 검증은 별개의 완료 조건입니다. 수집 결과를 승률 검증 완료나 실매수 신호로 표시하지 않습니다.
