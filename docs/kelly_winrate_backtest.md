# 승률 60% · 비중 20% 가설 백테스트

이 도구는 사용자의 설계도를 **실행 가능한 연구 가설**로 바꾼 오프라인 Python 시뮬레이터입니다. 실제 주문·API 키·유료 AI 호출 없이 CSV를 읽고 검출 근거와 포트폴리오 결과를 저장합니다.

## 시총 상위 우량주만 검사하기

2026-10-03 요청에 따라 실제 검사 진입점은 `scripts/screen_large_cap_kelly.py`로 제한했습니다. 기본 대상은 **코스피·코스닥 합산 시총 상위 100개 보통주**이며 `--top-n`으로 1~100개만 지정할 수 있습니다. 시총 순위를 먼저 고정하고 재무 탈락자를 101위 이하로 보충하지 않습니다. 전시장 종목 목록은 시총 순위 계산용 메타데이터로만 읽고, 가격 신호 계산은 상위 대상에만 수행합니다.

우량주 연구 기준은 기준일 거래량 양수, 공시 후 180일 이내, 양의 자본·누적 영업이익·누적 순이익, 부채비율 150% 이하입니다. 재무가 없거나 공개일·통화·출처·연결/별도 기준을 확인하지 못하면 보류합니다. 금융업도 같은 부채비율 규칙을 사용하므로 일반적으로 알려진 우량주 중 일부도 제외됩니다. 보통주 분류는 코드·이름 규칙이므로 공식 종목 유형과 관리종목 여부의 완전한 확인은 별도로 필요합니다.

명시적으로 수집하는 실행 예:

```powershell
python scripts/screen_large_cap_kelly.py --prices data/chart_analogue/closed_prices.csv --as-of 2026-10-01 --fetch-listing --fetch-financials --corp-codes C:/bitman_marketfloww/data/dart_corp_codes.json --env-file C:/bitman_marketfloww/.env --year 2026 --report-code 11012 --out data/kelly_research/large_cap_20261001
```

기존 프로젝트의 DART 키를 실행 중에만 읽습니다. 키를 출력하거나 결과에 저장하지 않습니다. `--fetch-*`가 없으면 외부 수집은 실행하지 않습니다. 로컬 자료로 재실행하려면 `--listing sources/listing_2026-10-01.csv --financials sources/financials.json`을 사용하세요. 정상 수집된 DART 응답은 24시간 재사용하고 원래 수집 시각을 보존합니다. 각 배치는 최대 50개이며, 100개 종목에는 최대 두 번의 DART 조회가 필요합니다. 시총 입력은 날짜별 [FinanceDataReader의 KRX 파생 캐시](https://github.com/FinanceData/fdr_krx_data_cache)이고 재무는 [OpenDART 주요계정 API](https://opendart.fss.or.kr/guide/main.do)입니다. 연결·별도 및 서로 다른 접수번호의 금액을 혼합하지 않습니다. 분·반기 손익은 누적 금액이 없으면 보류하며, 공시 당일의 공개 시각을 모르므로 접수일 다음 날부터 사용합니다.

결과의 의미는 세 단계로 구분합니다.

1. **시총 대상**: 기준일 상위 100개. 낮은 순위로 확장하지 않습니다.
2. **재무 기준 통과**: 위 연구 기준의 우량주 후보이며 매수 신호가 아닙니다.
3. **당일 가격 후보**: 재무 기준 통과 종목 중, 이전 60일 수익률 분포보다 현재 수익률이 2σ 이상 낮은 관찰 대상입니다. 현재 수익률은 기준 분포에서 제외합니다.

현재 시총을 과거로 소급하지 않습니다. 이 검사는 **기준일 코호트의 현재 후보 검사**이며, 과거 시총·정정 이전 재무 원본이 없어 `qualified_60pct_symbols=[]`, `historical_validation.status=not_verified`로 표시합니다. 가격 후보를 승률 60% 검증 완료 종목으로 표현하지 않습니다. 별도의 오프라인 백테스트 사용법은 아래에 있습니다.

첫 실제 실행은 가격 캐시의 마지막 날짜인 **2026-10-01**을 기준으로 했습니다. 상위 100개, 재무 통과 50개, 당일 2σ 후보 0개였습니다. 제외·보류는 부채비율 초과 39개, 순이익 비양수 9개, 순이익 자료 누락 1개, 재무 누락 1개입니다. 이는 10월 3일 실시간 가격 신호가 아닙니다. 생성 결과는 `data/kelly_research/large_cap_20261001/report.html`, 전체 근거는 `report.json`, 순위·재무 판정은 `universe.csv`에 저장합니다.

2026-10-03 장기 자료 대조에서 `KOSDAQ GLOBAL` 시장 표기 때문에 코스닥 일부가 순위에서 빠지는 오류를 수정했습니다. 같은 10월 1일 원자료로 재확정한 TOP100 결과는 `data/kelly_research/large_cap_20261001_v2/report.json`이며 재무 통과 52개, 당일 가격 후보 0개입니다. 긴 가격 이력·과거 시총·접수번호별 재무 확보 경로와 검증 범위는 [연구자료 확보 안내](kelly_historical_data_acquisition.md)를 확인하세요.

## 먼저 실행하기

저장소 루트에서 실행합니다. 새로운 패키지 설치는 필요 없습니다.

```powershell
python scripts/backtest_winrate_kelly.py --demo --out data/kelly_research/demo
```

`--demo`는 평균회귀와 실패 사례를 인위적으로 만든 **합성 데이터**입니다. 성공적인 실행이나 높은 데모 성과는 실제 주식 승률을 입증하지 않습니다.

실제 자료를 준비했다면:

```powershell
python scripts/backtest_winrate_kelly.py --prices prices.csv --fundamentals fundamentals.csv --train-end 2023-12-28 --validation-end 2024-12-30 --test-end 2025-12-30 --execution-price open --benchmark 069500 --out data/kelly_research/my_run
```

기간을 생략하면 입력 시장일의 앞 60%는 학습, 다음 20%는 검증, 마지막 20%는 최종 테스트로 나눕니다. 종목 선택과 켈리 추정은 검증 종료일에 동결됩니다. 최종 테스트 수익으로 다시 종목을 고르거나 파라미터를 맞추지 않습니다.

기존 MarketFlow 종가 캐시를 제한된 범위로 읽는 예:

```powershell
python scripts/backtest_winrate_kelly.py --prices data/chart_analogue/closed_prices.csv --symbols 003690,005930,000660 --execution-price close --out data/kelly_research/real_cache
```

이 캐시에는 실제 시가·거래량·역사적 재무자료가 없습니다. 재무 입력이 없으면 안전성 판정을 통과시키지 않으며, 조건 충족 종목 0개와 현금 유지가 정상 결과일 수 있습니다. 과거 가격을 최근에 일괄 수집한 조정주가 스냅샷을 과거 당시 확보한 데이터라고 표현하지 않습니다.

## 입력 계약

가격 CSV는 `symbol,date,close`가 필수입니다. 기존 `ticker|code`와 `current_price` 별칭도 지원합니다. `symbol`은 문자열로 읽어 `003690`의 앞자리 0을 보존합니다. `name,open,volume`은 추가할 수 있습니다.

아래 CSV 행은 형식을 보여 주는 가상 종목·가상 숫자이며 실제 시세가 아닙니다.

```csv
symbol,name,date,open,close,volume
DEMO_A,가상종목A,2025-01-02,100,102,250000
```

재무 CSV는 **해당 정보가 실제 공개된 날짜**를 `available_date`에 넣습니다. 회계기간 종료일을 공시일로 대신 쓰지 않습니다. 시가총액 단위는 원, 부채비율은 퍼센트입니다. 거래 불가·상폐 위험 확인 시 `tradable=false`를 넣습니다.

```csv
symbol,available_date,market_cap,debt_ratio,tradable
DEMO_A,2024-12-20,1000000000000,45.2,true
```

기본 재무 조건은 시가총액 3천억원 이상, 부채비율 150% 이하, 공개 후 180일 이내, 거래 가능 상태입니다. 이는 이 연구의 파라미터이며 부실·상폐 위험 제거를 보장하는 규칙이 아닙니다. 역사적 상장 구성과 상폐 환급·손실 자료가 포함되지 않은 CSV로 생존편향 제거를 주장할 수 없습니다.

종가와 시가는 같은 조정 기준을 사용해야 합니다. 비정상 숫자, 중복 종목/날짜, 잘못된 기간은 오류로 처리합니다. 시장일은 입력 전체 날짜의 합집합입니다. 전체 시장일 자체가 빠진 경우까지 판별하려면 완전한 거래일 달력을 포함한 입력이 필요합니다.

## 신호와 승률 검증

1. 현재 일수익률을 **현재를 제외한 이전 60일 수익률** 평균·표준편차로 표준화합니다. z-score가 -2 이하일 때 평균회귀 후보로 봅니다. 이전 변동성이 0이면 신호를 만들지 않습니다.
2. 신호 다음 시장일의 지정 가격에 가상 진입하고, 진입일에서 5시장일 후 같은 가격 종류로 청산합니다. 기본은 `close`이며 이는 **다음 날 종가 체결 가정**입니다. `open`은 실제 시가가 있어야 하며 종가를 시가로 바꾸지 않습니다.
3. 동일 종목 거래는 겹치지 않는 표본으로 셉니다. 학습/검증 기간 밖에서 청산되는 거래는 그 기간의 승률에 넣지 않습니다.
4. 두 기간 각각 거래 30개 이상, 순수익 기준 승률 60% 이상, 평균 이익/평균 손실 절댓값 1 이상, 양의 기대 순수익, Wilson 하한 60% 이상을 요구합니다. 손실 표본이 없어 손익비를 검증할 수 없는 경우도 무조건 통과시키지 않습니다.
5. 검증 기대 순수익 순으로 최대 3종목을 선택합니다. 조건 미달·자료 부족은 원인을 함께 반환합니다.

Wilson 구간은 이항 표본 가정의 통계 진단입니다. 표본을 비중복으로 만들어도 시장 국면·종목 간 상관과 다중검정은 남습니다. 한 번의 기간 분할만으로 과적합이 사라졌다고 주장하지 않습니다. [NIST 신뢰구간 설명](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm), [Bailey 등의 백테스트 과적합 연구](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf).

## 켈리와 자산 배분

`p=0.60, b=1`을 이항 베팅 공식에 넣으면 0.20입니다. 그러나 실제 주식의 +5%/-5% 수익과 베팅 원금의 +100%/-100%는 같은 모형이 아닙니다. 이 엔진은 완료된 **거래비용 차감 순수익률 R**로 `mean(log(1 + f*R))`를 최대화하는 비중을 0~1 범위에서 추정합니다.

기본 하프켈리 `f*0.5` 적용 후 종목당 최대 20%, 전체 최대 60%, 신규 투자 시 현금 최소 40%를 적용합니다. 이전 관측 변동성이 높은 경우 위험 비중을 줄이고, 정해진 낙폭 한도에 도달하면 다음 실행 시점에 현금화합니다. 20%는 자동 매수할 고정 비율이나 최적·완벽·파산 방지 보장이 아닙니다. [Kelly의 수익분포와 로그성장 정의](https://www.stat.berkeley.edu/~aldous/Real_World/kelly.html).

기본은 수량을 고정해 정해진 보유기간을 평가합니다. 가격 변동에 따른 실제 비중 이탈은 자산곡선에 기록됩니다. 신호·자격이 없는 종목을 하락했다는 이유로 자동 추가 매수하지 않습니다.

`--rebalance`를 추가하면 보유 중인 종목의 비중을 하루 한 번 재조정하는 실험 모드입니다. 이 경우 중간 매수·매도 비용과 위험 축소가 발생해 검출용 고정기간 표본과 실제 포트폴리오 손익이 달라집니다. 리밸런싱이 박스권에서도 무조건 이익을 만들거나 하락 추세에서 손실을 방지하지 않습니다.

## 비용과 해석

- `--cost-bps 5`: 매수·매도 각각 0.05% 수수료 가정.
- `--slippage-bps 10`: 각각 0.10% 체결 불리함 가정.
- `--sell-tax-bps 0`: 매도세 추가 가정. **0은 현행 한국 세율 안내가 아닙니다.** 해당 시장·상품·기간의 실제 값을 입력하세요.
- `--horizon 5`, `--lookback 60`, `--min-samples 30`, `--min-win-lower 0.60`, `--kelly-fraction 0.5`로 실험 조건을 지정할 수 있습니다. 바꾸어 반복한 모든 실험도 함께 기록해야 합니다.

자산은 시작값 1.0으로 정규화하고 소수 수량·무차입을 가정합니다. 거래단위, 가격제한, 실제 체결량, 배당·기업행동 처리의 완전성을 보장하지 않습니다. 가상 체결 비용은 자산에서 차감하며 마지막 테스트일에 보유분을 청산합니다. 보유 종목의 필수 가격이 없으면 조용히 제거하거나 미래 가격으로 채우지 않고 실패합니다.

출력 파일:

| 파일 | 확인할 내용 |
|---|---|
| `report.html` | 조건 충족/거부 이유, 자료 한계, 최종 테스트 성과 |
| `report.json` | 전체 설정·기간·통계·신호·입력 SHA256·가상 원장 |
| `qualification.csv` | 학습/검증 승률·손익비·표본·신뢰하한·켈리·거부 이유 |
| `equity_curve.csv` | 날짜별 자산·현금·실제 비중과 낙폭 |
| `fills.csv` | 가상 매수/매도 날짜·수량·가격·비용·사유 |

종목별 최종 표본·승률과 `evaluation`의 적중/오검출/미검출/올바른 제외는 **선정과 비중을 동결한 이후**에 계산합니다. 같은 비용 가정에서 완료된 고정 보유기간 신호의 순수익이 양수면 적중 대상, 0 이하이면 손실 대상입니다. 선택된 종목의 손실 신호는 오검출, 미선정 종목의 수익 신호는 미검출로 셉니다. 이는 입력 범위의 신호 기회 평가이며 전시장 미검출 수나 실제 주문 승률이 아닙니다. 이 결과를 보고 같은 테스트 기간에 다시 맞추면 독립 최종 테스트의 의미가 사라집니다.

먼저 거부 이유와 표본 수를 보고, 그다음 최종 테스트 순수익·최대 낙폭·비용·벤치마크를 비교하세요. 후보가 없으면 입력이나 조건을 사후 변경해 억지로 높은 승률을 만들지 않습니다. 이 구현은 백테스트 연구 도구이며 실제 검출력 입증에는 시점별 자료와 이후 신규 기간의 독립 검증이 필요합니다.
