# AlphaLab 입력 신뢰성과 0건 검출 재점검

## 원인과 변경

기존 v2에서는 이미 확인한 12개 과거 결정일의 발견 조건 통과 18건이 최종
경제성 문턱에서 모두 탈락했다. 계산 오류로 개수를 0으로 만든 것은 아니지만,
드문 종목별 사례와 검증되지 않은 불확실성 차감값을 결합해 현재 종목을
선별하는 기능이 사실상 정지했다. 필터 숫자를 내려 그 구간에 맞추지 않았다.

NAVER 입력의 거래시장·기업행사 수정·당시 제공 내용은 검증되지 않았다.
20:30 이후 수집도 과거 가격 수정 여부를 보증하지 않는다. 신규 경로는
프로젝트의 기존 KIS 인증·호출 간격을 사용해 KRX J / 일봉 D / 수정주가 요청
0을 명시하고 실제 취득 시각과 원본 해시를 저장한다. NAVER와 혼합하지 않는다.
KIS 요청 형식의 명시가 기업행사·당시 자료의 정확성 인증은 아니다.
시장 J·일봉 D·수정주가 요청 0과 호출당 100건 계약은
[한국투자증권 공식 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_daily_itemchartprice/inquire_daily_itemchartprice.py)와 대조했다.

기존 정책 코드·최초 결정·종료 결과는 보존한다. 신규 입력, 고정 v3 공동
검증, 실험적 v4 문맥 추정과 향후 관측은 별도 파일에 둔다. GET은 저장
상태만 읽으며 수집·학습·Telegram 전송을 실행하지 않는다.

## 실제 입력과 고정 검증 결과

2026-10-21 가격 세션의 재무 적격 52종목, 38,484개 일봉을 취득했다.
48종목은 요청한 756세션을 갖고, 4종목의 실제 짧은 이력은 보충 생성하지
않았다. 실제 취득은 10월 22일 09:09:38~09:19:44 KST다. 030200의 일시적
호출 실패는 앞서 성공한 51종목을 유지하고 해당 종목만 재시도했다.

입력 지문은 `5dd3c4b1f16cb71eb9111096303feb478aa2ae04acddc82cfa69f937d9571f45`다.
현재 가격 구조 조건은 5종목이 통과했다. 먼저 선언한 v3 고정 공동 검증은
형성 490건 평균 순손익 +0.8110%, 비용 2배 +0.4074%였으나 최근 126세션
비교 115건은 **-2.4990%, 비용 2배 -2.8894%**였다. 이 음수 결과와 v3의
0건 제안은 그대로 보존한다. 해당 평균은 계좌 수익률이 아니다.

이후 별도 선언한 v4는 형성 구간에서 타 종목의 조건별 유사 사례를 사용한다.
학습 종료일은 2026-03-31이며 이후 비교 구간은 학습에 사용하지 않는다.
대상 종목을 이웃·표준화·축소 평균에서 제외한다. 시간 블록별 평균을 먼저
계산하며 60개 사례를 60개의 독립 시행으로 간주하지 않는다.

첫 고정 실행은 현재 구조 통과 5종목 중 문맥 관측 평균과 축소 기대값이
일반·비용 2배에서 모두 양수인 2종목을 반환했다. 아래 값은 10월 21일
KIS 종가에 근거한 참고 계획이며 다음 실제 시가에 다시 계산한다.

| 종목 | 기준 진입 | 추격 상한 | 참고 손절 | 참고 목표 | 연구 참고 비중 |
|---|---:|---:|---:|---:|---:|
| 대덕전자 353200 | 132,000원 | 134,640원 | 121,440원 | 153,120원 | 1% |
| 삼천당제약 000250 | 212,500원 | 216,750원 | 195,500원 | 246,500원 | 1% |

대덕전자는 타 종목 31개·30시간 블록의 60사례, 삼천당제약은 33개·32블록의
60사례다. 비용 2배 축소 추정값은 각각 +1.2518%, +0.6845%다. 과거 사례의
양수 순손익 빈도는 26/60=43.3%, 29/60=48.3%이며 미래 승률이 아니다.
손익비·분포를 사용하는 추정이라 60% 승률을 요구하거나 꾸미지 않는다.

v4는 **실험적 조건부 제안·전향 검증 중**이다. 이미 관측한 음수 v3 비교를
v4의 독립 검증 성과로 표현하지 않는다. 위 양수 추정만으로 수익 개선을
입증했다고 주장하지 않는다. 현재 생존 코호트, 당시 자료·기업행사 미검증,
가상 비용·갭·호가·체결 차이는 남는다.

## 운영·검증 계약

실제 생성일 이후의 공식 거래일에만 진입 계획을 고정한다. 기존 시가를
소급 적용하지 않는다. 상한 초과·손절선 이하·목표 이상 시가는 미체결이다.
허용 시가에서는 ATR 손절·목표를 다시 계산하며 최대 10거래일을 관측한다.
단일 종목 참고 비중 1%, 쿼터 켈리, CIO 승인 노출 0과 주문 비활성을 유지한다.

새 선언 이후 서로 다른 60결정일과 10세션 성숙을 관측하고 자동 승격하지
않는다. 같은 날 재실행, 동일 가격 세션 재검출은 표본을 늘리지 않는다.
신호·이미 소비한 시세의 수정/삭제는 원래 결과를 보존하고 집계에서 제외한다.
실패한 부분 갱신은 완료된 입력·분석을 유지해 해당 단계만 복구한다.

입력·인과성·체결·저장·권한·모바일·알림 중복 방지 회귀검증, 전체 Python/
프런트 테스트와 빌드, 독립 리뷰와 CI를 수행한 뒤 배포한다. 최종 운영 증거는
비공개 `data/reviews/alphalab-rebuild-20261022/`에 별도로 기록한다. 이 문서가
배포 성공이나 수익성 검증을 대신하지 않는다.
