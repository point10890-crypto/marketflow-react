## 검증과 운영 복구

- 통계 선택·성숙일·중복 처리·손익 계산 parity, 오류 시 이전 보고서 보존을 회귀 검증한다.
- 관리자 200 / 회원 403 / 비로그인 401, private no-store를 배포 후 확인한다.
- 미국 자료는 실제 가격 세션 날짜 및 새 산출물 시각을 확인한다. 재사용한 AI 해석 시각은 별도로 남긴다.
- US 자료 4개는 07:00/08:00 공개 시각과 2시간 유예를 기준으로 마지막 NYSE 마감 세션을 검사한다. 주말·휴장일 경과를 단순 TTL 증가로 대신하지 않으며, 유예 중에도 이전 미완료 세션을 보존한다. 이 시각 검사는 가격 CSV의 실제 세션 검증을 대체하지 않는다.
- 전체/빠른 미국 브리핑 모두 시장 스냅샷 실패 시 기존 파일을 보존하며 유료 AI 호출 전에 중단한다.
- Top3 저장본 누락·손상·저장 실패는 메모리 결과가 생성되어도 최신 완료로 간주하지 않는다.
- 완료한 수집·압축·보고서 단계는 보존하고 실패한 단계만 복구한다. 성공 기록은 실제 결과 검증 뒤에만 남긴다.
- 새 전략 최적화, 실계좌 주문, 결제, 계정·키 변경 및 임의 알림 전송은 이 변경에 없다.
- 배포 전후 회원·구독 데이터 지문을 비교하고, MiniPC 예약 반복과 공개 API/운영 화면을 검증한다.

릴리스별 실행 증거는 `data/operations/control_center/`와 관리 작업트리의
`data/control-center-evidence/`에 저장한다. 키·환경 파일·회원 정보는 증거에 포함하지 않는다.

## 미국 차트 유니버스 티커 정정

운영 US 차트 복구에서 고정 100종목 중 `MMC`만 가격 차트를 만들지 못했다.
[Marsh 공식 발표(2025-12-29)](https://www.marsh.com/en/corp/about/news/marsh-mclennan-to-change-nyse-symbol-to-mrsh.html)는
NYSE 티커가 **2026-01-14부터 `MMC` → `MRSH`**로 변경되고 브랜드가 Marsh가 된다고 명시한다.
해당 변경 당시 법인명과 CUSIP는 유지됐다.
[SEC 2025 회계연도 10-K(2026 제출)](https://www.sec.gov/Archives/edgar/data/62709/000006270926000022/mrsh-20251231.htm)에서도
MRSH와 Marsh 브랜드를 확인했다.

`main_us.py`의 현재 차트 대상 키를 `MRSH`, 표시 이름을 `Marsh`로 정정한다.
기존 100종목 구성에서 동일 발행사의 티커만 바꾸며 결과 개수를 임의로 채우지 않는다.
공용 섹터맵에는 `MRSH: Fin`을 추가하고 과거 산출물을 읽는 `MMC: Fin`은 보존한다.
과거 가격·분석 파일은 다시 쓰지 않는다. 실제 새 차트와 분석 결과의 성공 여부는 별도 실행 증거로 검증한다.

## 실제 복구에서 추가 발견한 데이터 무결성 문제

- 미국 가격 재수집 결과 503개 중 502개만 최신이었다. 신규 편입 OKTA의 단독 과거 배치도 yfinance가 MultiIndex 열을 반환하는데, 요청 개수가 하나라는 이유로 평면 열로 취급해 병합에 실패했다. 실제 반환 열 구조를 기준으로 정규화하며 단일/복수/과거 평면 형식을 회귀 검증한다. 기존 종목 가격을 보존한 단일 종목 보강과 영향 입력 비교를 통해 완료된 유료 분석을 불필요하게 반복하지 않는다.
- 야간 분석의 피드백 갱신은 동일한 약 198MB 가격 CSV를 최대 50회 읽었다. 워크플로 선택·진입일·성숙 조건·성과 계산을 유지하며 한 번의 갱신에서 필요한 종목 합집합을 한 번 읽고 공유한다. 워크플로별 출처 행 수와 날짜 범위는 각 부분집합으로 보존하고, 읽는 중 원본이 바뀌면 기존 결과를 덮기 전에 중단한다.
- 저장공간 작업은 이미 압축한 수십만 run의 헤더까지 다시 읽어 후보 탐색이 지연됐다. 파일 메타데이터로 이미 압축된 run을 먼저 제외하되, 리다이렉트·하드링크·최근 수정 파일 거절과 실제 압축 대상의 완료 헤더·경로·해시 검증을 유지한다. 이전에 검증된 압축 결과는 보존하며 쓰기를 시작하지 않은 탐색 단계만 새 구현으로 재개한다.
- `Institutional Trend`는 실제 운영 입력이다. 2026-11-06 수집은 기존 Naver 주소가 신규 페이지로 이동해 표를 찾지 못했으나 정상 종료로 보고됐으며, 저장 CSV는 2026-09-10 상태였다. 실패를 최신 성공으로 기록하거나 오래된 수급의 날짜를 오늘로 바꾸면 안 된다. 수집 응답 형식, 원본 거래일, 수집 시각과 소비 단계의 신선도를 각각 검증한다.
- `cumulative_performance.json`은 신규 종가베팅 결과 뒤 삭제되고 조회 시 생성되는 캐시다. 파일 부재만으로 정기 수집 실패로 분류하지 않는다. Crypto Backtest는 수동 연구 산출물이므로 정기 가격 데이터의 갱신 기한과 구별한다.

실제 8,000-run 백테스트 복구는 164.875초에 완료됐지만 결과는 기준 대비 손실이며 기존 승격 기준을 통과하지 않았다. 운영 복구와 투자 성과 개선은 별개의 검증이다. 이 작업은 결과를 좋게 보이도록 표본·기준·손익을 바꾸지 않는다.
