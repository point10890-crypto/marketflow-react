# 만료 하루 전 앱 알림·재구독 카드

- 서버의 구독 만료 시각까지 `0 < 잔여시간 <= 24시간`이면 앱 상단 알림과 재구독 팝업을 표시한다. 날짜만 반올림하지 않는다.
- PRO, AI 브레인, 제갈공명의 유효 이용권 중 먼저 만료하는 항목을 안내한다. AI·제갈공명 만료일이 같으면 하나의 결합 안내로 표시한다.
- 관리자·정지/거절 계정·무기한 UltraPRO 기본 이용권·일시정지된 PRO 기간에는 잘못된 만료 안내를 만들지 않는다. PRO는 실효 만료일을 우선한다.
- API의 시간대 없는 ISO는 UTC로 해석하고 화면은 한국시간의 실제 종료 시각을 표시한다.
- 팝업을 열기 전 기존 구독 상태 API로 해당 회원과 신청 대기 여부를 확인한다. 서버가 갱신된 만료일을 반환하면 캐시된 만료일로 팝업을 띄우지 않고 회원 정보를 다시 조회한다.
- 기존 신청 대기는 승인 상태로 안내한다. 조회 실패는 다시 확인만 제공하며 재입금 버튼을 열지 않는다.
- PRO 갱신은 `plan=pro&renew=1`, AI·제갈공명은 현재 등급에 맞는 기존 결제 안내로 직접 연결한다. 입금·신청·승인 대기 화면 위에는 팝업을 띄우지 않는다.
- 나중에 보기를 누르면 상단 안내는 유지하고 팝업만 30분간 숨긴다. 회원·만료 항목·만료 시각·현재 요금과 신청 플랜별로 구분하며, 다시 열기 전에 신청 상태를 재확인한다. 만료일이 같아도 등급 변경으로 요금이나 신청 경로가 달라지면 이전 안내를 폐기한다.
- 앱을 켜 둔 경우 1분마다, 창 포커스 또는 다시 표시되는 시점에도 상태를 확인한다. 만료 시 기존 재구독 흐름으로 전환한다.

이 변경의 알림은 앱 내 안내다. 앱을 닫은 회원에게 새 브라우저 푸시·문자·메일을 보내거나 권한을 요청하지 않는다. 기존 서버의 만료 감시와 이미 연결된 텔레그램 경로는 변경하지 않는다. 구독 요금·승인·기존 회원 데이터도 변경하지 않는다.
