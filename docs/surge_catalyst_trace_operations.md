# 급등 이유 역추적 운영

사용 위치: AI Brain → 제갈공명 **뉴스·재료 검증** → **급등 이유 역추적**.
직접 주소: `/dashboard/ai-bain/catalyst-validation#surge-traces`.

## 읽는 순서

1. 종목과 상승 관측 시각을 본다. +5%·거래대금 20억 원 이상은 역추적 대상 기준이며 매수 조건이 아니다.
2. 유력 재료 후보와 원문을 본다. 기사·공시가 있다는 사실과 실제 상승 원인이 입증됐다는 주장은 다르다.
3. 발행 시각, 가격 관측 시각, 최초 수신 시각을 비교한다. 가격 관측 전에 발표됐어도 뒤늦게 수집했다면 과거에 알고 있던 신호로 계산하지 않는다.
4. 사후 보도, 부정·혼합 재료와 출처별 오류를 함께 확인한다. 날짜만 있는 당일 공시는 선후 미확인이다. 유가·환율·금리 등 외생 변수와 주가 반응을 명시적으로 연결한 기사는 보도된 상승 배경으로 구분하며, 독립적인 인과 검증으로 취급하지 않는다. 규제 우려·전망·질문형 제목은 상승 재료 요약에 올리지 않는다.
5. 원인 미확인은 조사한 출처에서 적합한 재료를 찾지 못했다는 뜻이다. 출처 실패나 전체 시장을 다 보았다는 뜻으로 바꾸지 않는다.

## 자동 흐름

`data/screener_leading_latest.json`의 실제 관측 → 세션·종목별 최초 관측 보존 → Omni/BusinessPost 저장 기사 역조회 → 부족한 기업 뉴스 검색 및 OpenDART 전체 공시 목록 → 시각·발행사·중복·사건 분류 → 별도 저장 결과 → 회원 화면.

상승률·거래대금으로 최대 20종목을 선택한다. 기존 매수 등급은 역추적 대상 선정에 쓰지 않는다. 시장 식별 실패, paper 모드, 미래·부정확한 가격은 제외한다. 장외의 마지막 저장 시세는 실시간 시세나 공식 종가로 표시하지 않는다. 스크리너가 전체 시장을 완전히 수집했다고 가정하지 않는다.

외부 뉴스는 무료 Google News 한국어 RSS 검색을 사용한다. 검색엔진은 원문 발행사가 아니며 검색 결과 수는 독립 확인 수가 아니다. 본문을 자동 재배포하거나 LLM으로 이유를 생성하지 않는다. DART 기업코드·종목코드·기업명을 대조하며 공시 제목 확인을 실적 금액 검증으로 승격하지 않는다.

## 실행과 저장

```powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.run_surge_trace
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install_surge_trace_task.ps1
```

Task `MarketFlow-Surge-Catalyst-Trace`: 시작 시·5분 간격, `IgnoreNew`, 실행 상한 2분. 워커는 80초와 한 번에 최대 5종목으로 외부 조회를 제한한다. 기존 시세·뉴스 수집 작업 및 Flask 요청 스레드와 분리된다. 유료 모델·주문·알림 발송을 추가하지 않는다.

저장은 `data/surge_trace/`. 같은 세션의 최초 가격 관측은 보존하고, 성공한 출처는 캐시 만료 전 재호출하지 않는다. 실패한 출처는 별도로 재시도한다. 새로운 근거는 수신 시각을 새로 기록하며 이전 결과를 소급해 성공 신호로 만들지 않는다. 원본 AlphaLab 결정·순위·손익 원장은 수정하지 않는다.

`GET /api/admin/mirofish/kongming/surge-traces`는 admin 또는 현재 Kongming 이용권 회원만 접근한다. `private/no-store`, 저장 조회 전용이며 강제 갱신·임의 URL·유료 추론을 허용하지 않는다. UI는 보이는 동안 30초마다 저장 상태를 조회한다.

## 배포 검증 항목

- 시간·종목 일치·중복·부분 실패·재시도·최초 관측 불변성 테스트.
- 비회원/만료 회원 차단, 관리자/번들 접근, GET 외부 호출 금지.
- 실데이터 종목·원문·발표·수신 시각과 화면 일치.
- 반복 워커의 완료 단계 재사용, 작업 스케줄 및 public health.
- PC 및 모바일 세로 화면. 실제 검증 결과는 `data/operations/`의 별도 영수증에 기록한다.
