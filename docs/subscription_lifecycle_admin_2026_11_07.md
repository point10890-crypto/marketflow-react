# 구독 만료·관리자 직권 처리 개편

## 회원 만료 흐름

- 기본 구독 만료: 계정을 보존하고 PRO 50,000원 / PRO+AI Brain·제갈공명
  100,000원 신청으로 연결한다. 승인 대기 중이면 추가 입금 대신 신청 상태를 표시한다.
- AI·제갈공명 만료: 기본 구독이 유효하면 50,000원 추가 구독으로 연결한다.
  AI 이용 중 정지했던 PRO 기간은 실제 AI 종료 시각부터 다시 차감한다.
- 자동 점검이 늦어져도 지연 시간을 PRO 무료 기간으로 더하지 않는다.
  API와 화면은 자동 작업 전에도 보정한 만료일로 접근·재구독 상태를 판단한다.
- 대기 신청이 철회되면 취소 상태와 재신청 버튼을 제공한다.

## 관리자 구독 탭

- 회원 검색: 이름·이메일·회원번호, 이용 중 / 3일 내 만료 / 만료·재구독 / 미신청 필터.
- 회원별 대기 신청 승인, 기본 등급 부여·재활성화, PRO 연장,
  AI Brain·제갈공명 공동 부여·연장·철회, 전체 구독 만료, 회원 삭제.
- 대기 신청 철회: 해당 신청만 종료하며 기존 이용권을 유지한다.
- 신청 내역 삭제: 작업 목록에서 숨긴다. 원본 행과 관리자 감사 기록을 보존하며
  승인 상태·금액 집계·이용권에는 영향을 주지 않는다. 승인 건의 이용권 철회는 회원 관리에서
  대상 범위(AI 묶음 / 전체)를 명시해 수행한다.
- 회원 계정 삭제: 대상 이메일을 재입력한 뒤 기존 회원 삭제 API를 호출한다.
  작성 글·댓글·구매·구독 신청이 삭제되고 관리자 감사 기록은 보존된다.
- 관리자 계정 전체 이용 권한은 구독 만료·철회 대상이 아니다.
- 대기 결제 신청이 있으면 수동 부여로 우회하지 않고 해당 신청을 승인하거나
  철회한 다음 처리한다. 철회·삭제 및 감사 기록은 같은 트랜잭션이다.

## 검증 범위

- 격리 SQLite에서 실제 인증·권한·관리자 API로 부여/철회/삭제/롤백 검증.
- 지연된 만료 점검, PRO 보존 기간, 재신청, 승인 전후 및 반복 처리 검증.
- Vitest, TypeScript/Vite 빌드, ESLint, PC·모바일 브라우저 확인.
- 실제 회원 구독이나 결제 데이터는 검증 목적으로 변경하지 않는다.
- 기존 DB에는 `subscription_requests.archived_at`만 추가한다. 반복 적용과
  기존 승인 상태·금액 보존을 SQLite에서 검증한다.
