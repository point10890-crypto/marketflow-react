# 수익 기회 검출 엔진 사용·운영 기준

차트 유사 사례 화면의 에이전트 제안에서 최대 세 종목을 확인한다. 기존 시총 상위100 / 재무 필터 유니버스와 추세 지속, 거래량 돌파, 과매도 회복 조건을 사용한다. 이번 정책은 기본 세 종목으로 잘린 결과가 아니라 모든 근거 통과 종목을 비교한다.

## 투자자가 읽는 순서

1. **종목과 행동:** 매수 후보의 매력과 지금 가격에서 진입 가능한 상태를 따로 확인한다. 다음 장 대기는 후보가 없다는 뜻이 아니다.
2. **선정 이유와 다음 행동:** 왜 이 종목인지, 현재 조건이 무엇인지, 어떤 가격 조건을 기다리는지 확인한다.
3. **가격 계획:** 진입 구간, 손절, 목표, 최대10거래일 계획을 본다. 종가 기준 계획과 관측 가격 기준 계획은 구분한다. 가격 관측은 체결을 의미하지 않는다.
4. **제안 비중:** 순수익 표본으로 계산한 일반화 켈리에1/4을 적용하고 단일 종목5%, 계획 계좌 위험1% 상한을 적용한 연구 참고치다. 자동으로20%를 할당하지 않는다.
5. **자료와 근거:** 표본 수, 비용2배 순수익, 불확실성 차감, 자료 시각과 미확인 사항을 펼쳐 본다. 순위 점수는 미래 승률이 아니다.

현재가가 추격 상한을 넘거나 손절/목표에 도달하면 즉시 진입 제안이 유지되지 않는다. 휴장, 개장 전, 만료, 자료 지연, 공식 달력 또는 출처 연결 오류에서는 가격 확인이나 다음 장 대기로 표시한다. 실제 주문은 투자자가 판단한다.

## 시스템 처리

`검사한 전체 후보 → 비용·불확실성 순위 → 상관관계 노출 차감 → 최대3종목 → 원본 결정 고정 → 공식 달력·가격 감시 → 시간에 따른 읽기 전용 제안`

확인 구간은 통과/실패에만 사용하고 순위는 형성 구간의 비용2배 순수익을 사용한다. 표준오차 차감은 순위 산정 방식이며, 상관된 표본이나 반복 검색에 대해 유효한95% 신뢰구간을 보장하지 않는다. 유효한 상관 자료가 없는 종목을 독립 분산 효과가 있다고 표현하지 않는다.

기존 연구 결과와 BUY3 원장·해시는 유지된다. 새 정책은 `profit-opportunity-v1`으로 식별되고, 별도 `decision_engine/` 저장소에 발행 결정과 자료 관측을 기록한다. 동일 결정의 재실행은 발행 시각과 진입 기한을 연장하지 않는다. GET은 수집, 학습, 파일 복구를 실행하지 않는다.

## 성과 해석과 한계

새 원장의 발행·대기·만료·가격 관측·미관측 숫자는 **매매 성과가 아니다**. 미관측은 미체결 확정이 아니며, 관측은 체결 확정이 아니다. 계좌 체결 증빙 없이 수익률이나 실현손익을 만들지 않는다.

현 유니버스의 생존 편향, 과거 원자료 공개 시각과 기업 행동 조정 미검증, 같은 장세의 표본 의존성, 종목·조건 반복 검색의 편향이 남아 있다. 따라서 새로운 정책은 연구 후보 선정 정책이며 독립 검증이나 수익 보장이 아니다. 전향 성과 평가는 사전 고정한 평가 일정과 실제 진입 계약을 갖춘 별도 증거로 판단해야 한다.

## 운영

기존 `scripts/run_alpha_lab.py` 연구 실행과 `scripts/run_alpha_lab_monitor.py` 공식 달력·가격 감시 경로에 연결한다. 기존18:45 연구 / 장중5분 감시 정의를 재사용한다. 작업 설치 상태나 운영 배포를 소스 변경만으로 완료했다고 판단하지 않는다.

서비스 API와 권한은 그대로 `/api/admin/mirofish/alpha-lab`의 활성 AI Brain 또는 관리자 권한을 사용한다. 로컬 검증은 독립 출력 폴더와 테스트 계정으로 수행하며 운영 사용자 DB, API 키와 실제 주문에 접근하지 않는다.
