# 종목 판단에 20거래일 매물대 연결

사용자 요청: 별도 제갈공명 뉴스 화면에만 둔 매물대 분석을 종목 판단 엔드포인트와 화면의 판단 근거에 포함한다.

## 계약

- `/api/kr/decision/<symbol>` 응답에 `technical_analysis`를 포함한다. 기존 신호, 독립 근거 수, 합의·신뢰 상한은 그대로 둔다. 같은 KIS 가격 파생치를 새 독립 찬성표로 세지 않는다.
- 파일 기반 어댑터는 정확한 종목·출처·수집 시각·완료 거래일·계산 증거를 대조한다. 20일 매물대의 지지·저항·POC와 거래량·비중·대금, 기준 종가 대비 거리만 결정론적으로 설명한다.
- 브리프/심층 캐시와 완료 잡 응답에도 조회 시점의 저장 매물대를 덧붙인다. 기존 저장 판단이나 당시 분석 입력을 수정하지 않는다.
- 새 심층 분석은 검증된 ready 매물대 요약을 기존 토론 문맥에 전달하고 사용한 fingerprint/as_of/fetched_at/context_text를 기록한다. 추가 LLM 호출이나 과거 결과 재실행은 없다.
- `GET/POST /api/kr/decision/<symbol>/technical-profile`: 조회는 선택 종목의 저장 자료만 읽고, POST는 가격 수집 대기열에만 등록한다. 종목 판단과 동일한 관리자/AI Brain/결합 플랜 권한을 적용한다.
- 화면의 명시적 종목 조회가 끝났을 때 부족한 매물대 수집을 한 번 요청하고, 기다리는 동안 가벼운 기술 결과만 조회한다. 종목·로그인 변경 시 늦게 도착한 응답은 버린다. 다른 종목의 매물대를 대신 표시하지 않는다.
- KR 일봉 분석만 지원한다. US 티커에는 KR 가격대를 붙이거나 자료 부족 감점을 추가하지 않는다.

## 구현·검증 범위

어댑터와 원장 회귀 검사 / 기존 판단·캐시·토론·권한 통합 검사 / 선택 종목에 묶인 모바일 카드·비동기 경합 검사 / 전체 프런트 테스트·빌드 / CI / 배포 후 실제 종목 판단 응답·예약 수집·PC/모바일 확인.

기존 작업트리의 커뮤니티 수정, 구독 정책, 실계좌 주문, 기존 뉴스 검증·TOP3 결정은 변경하지 않는다.
