The user requests useful buy candidates, a fundamental data/selection review, tests and verified production deployment. Existing v2 is correctly empty, but its per-symbol rare-event evidence and uncalibrated final uncertainty hurdle rejected all 18 discovery survivors in the already inspected replay. That replay is diagnostic, not a new optimization objective.

Implement a separate, versioned candidate desk. Keep every file in `detection_v2_store._CODE_FILES` unchanged and continue the existing v1/v2 experiments. No source replacement in their journals. ### Fixed hypothesis, declared before new outcomes are computed

One deterministic cross-sectional trend/relative-strength setup replaces per-stock strategy shopping. On a contiguous 61-session prefix require close>SMA60, SMA20>SMA60, positive 20/60-session return, above-median same-date quality-cohort return20, mean20 traded value >= KRW1bn, positive volume and price no more than 12% above SMA20. Rank by same-date percentile relative return20 (45%), momentum60 (30%), proximity to prior20 high (15%) and volume ratio (10%, capped3). The cohort median is not an official market benchmark.

Use the latest 756 sessions: 504 formation sessions, a 10-session embargo, then126 confirmation sessions, with earlier causal warmup. Historical selection uses the identical setup and top-three ranking; no overlapping position for the same symbol. Labels enter next union-session open, use shared ATR14x2/8% loss cap/2R/10-session policy and 5/5/20bps costs, doubled-cost stress on identical fills. Exclude labels unresolved by their phase cutoff and any sparse holding interval. Pool completed selected events across symbols, but aggregate uncertainty/coverage in nonoverlapping ten-session signal-date blocks; same-date peers are not independent samples.

Execution clarification from independent synthetic contract review, before inspecting new KIS outcomes: historical and forward entries both use the original signal close*1.02 ceiling and signal bracket. An opening above that ceiling, at/below the reference stop or at/above the reference target is unfilled. A target at/below the ceiling invalidates that proposal. The signal close is a reference, not a hard lower entry floor; a lower opening above the stop may enter. Accepted fills recalculate ATR brackets from the actual open. Warning/info flags are normalized only on execution copies. Future observed nontradable holding outcomes remain preserved but excluded from comparable evidence, matching historical exclusions. Missing official entry data never permits a later opening to substitute. These are correctness repairs to align displayed and measured rules, not threshold changes selected from profit outcomes.

Require >=30 formation and >=10 confirmation completed events, >=5 formation and >=3 confirmation calendar blocks, >=5 unique formation symbols, and positive mean net AND stressed returns in both chronological phases. No test-period winner selection or threshold search. A pool failing these checks cannot produce buys. Candidate ranks express current structure, not probability. Fractional net Kelly comes from formation returns; cap a reference weight at5% and planned account loss at1%. Return up to3 candidates, never padding from failures. Show funnel counts and exact rejection categories when empty. Report block statistics and unverified historical cohort/vintage limitations; do not call pooled returns account P&L or independent market alpha.
