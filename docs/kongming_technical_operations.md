# 제갈공명 20거래일 매물대 에이전트

## 화면과 해석

AI 브레인 → 제갈공명 뉴스·재료 검증 → **기술적 분석 에이전트 · 20일 매물대**.
직접 주소: `https://bit-man.net/dashboard/ai-bain/catalyst-validation#technical-profiles`.
저장된 종목명으로 선택하거나 새 종목의 영문·숫자 6자리 코드로 수집을 요청한다.

- 최대 거래량 구간(POC): 집계 기간 중 추정 거래량이 가장 많은 가격 구간.
- 지지 후보: 기준 종가보다 완전히 아래에 있는 구간 중 추정 거래량이 가장 많은 구간.
- 저항 후보: 기준 종가보다 완전히 위에 있는 구간 중 추정 거래량이 가장 많은 구간.
- 규모: 구간별 주식 수, 전체 거래량 중 비중, 추정 거래대금. 전체 24개 구간도 함께 표시한다.
- 지지/저항이 없으면 해당 가격대 없음을 표시한다. 실제 보유 물량·미체결 매도 잔량을 뜻하지 않는다.

최근 **완료된 20거래일**을 사용한다. 20:30 KST 이전에는 당일 일봉을 포함하지 않는다.
KIS KRX 비수정 일봉의 저가~고가 범위에 거래량과 실제 거래대금을 각각 균등 배분한다.
균등 배분 모델은 일봉 기반 추정이며 실제 체결가별 거래량 분포와 다르다.
24개 구간의 합계는 원본 거래량·거래대금 합계를 각각 보존한다. 전 기간 가격이 같으면 1개 구간이다.
종가와 가격대는 주문가가 아니며, 소수점 계산 결과는 화면에서 원 단위로 반올림한다.

## 자동 운영

- 작업: `MarketFlow-Kongming-Technical`, MiniPC `C:\bitman_marketfloww`.
- 설치: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install_kongming_technical_task.ps1`.
- 실행: `.venv\Scripts\python.exe -X utf8 -m scripts.run_kongming_technical`.
- 시작 시 및 1분마다 실행; 중복 실행 금지, 최대 3종목/회, 작업 제한 2분.
- 최근 기사 연결 종목을 자동 등록하고 수동 요청 종목을 우선 처리한다.
- 종목당 완료 일봉 창이 바뀔 때만 재수집한다. 휴장으로 창이 같으면 기존 성공 결과를 재사용한다.
- 기사 후보는 마지막 확인 후 3일, 수동 요청은 7일 동안 갱신 대상으로 둔다.
- 최초 실패는 15분 간격, 연속 3회 이상 실패는 1시간 간격으로 자동 재시도한다. 재요청으로 대기 시간을 무시할 수 없다.
- 실패 시 마지막 성공 자료를 보존하고 화면에 이전 결과임을 표시한다. 가격 사건·20일 자료 부족은 가격대를 표시하지 않는다.
- 최대 500개 활성 등록/32개 수동 우선 요청. 용량이 차면 만료된 등록 참조만 정리하며 원본 증거와 계산 기록은 삭제하지 않는다.
- 화면 30초 갱신은 저장 결과만 조회한다. KIS 시세 수집·AI 호출을 화면 요청에서 실행하지 않는다.
- 유료 LLM, 자동주문, Telegram 발송, 기존 TOP3/CIO 판단은 사용하거나 변경하지 않는다.

## 자료와 권한

KIS 지수 일봉 `FHKUP03500100`에서 양수 거래량이 확인된 최근 20개 날짜를 사용한다.
KIS 종목 일봉 `FHKST03010100`, `J/D/1`(KRX/일봉/비수정), 1회 요청 범위로 취득한다.
종목 식별, 중복 날짜, 미래 날짜, OHLCV 수치, 기업행사 표시를 검사한다.
지수 관측은 공식 휴장일 원장의 완전성을 인증하지 않으며 미제공 기업행사 표시는 확인할 수 없다.

`GET /api/admin/mirofish/kongming/technical-profiles`는 저장 결과만 반환한다.
`POST` 동일 주소의 `{ "symbol": "005930" }`는 비동기 대기열 접수(202)다.
관리자 또는 유효한 제갈공명 이용 권한이 필요하며, 응답은 허용된 필드만 반환한다.

`data/kongming_technical/`:

- `state.json`: 등록·실패·재시도·완료 상태
- `calendar.json`: 수집 기준일별 확인된 20거래일
- `profiles/{symbol}.json`: 마지막 완료 결과
- `history/{symbol}/{fingerprint}.json`: 변경하지 않는 입력/계산/달력 증거
