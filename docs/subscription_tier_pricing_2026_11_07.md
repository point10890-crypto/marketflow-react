# 등급별 AI Brain·제갈공명 구독 개편

2026-11-11 신규 신청 정책 확인: [현재 플랜과 1만원 전환 종료](subscription_policy_2026_11_11.md).
기존 5만원 AI 추가/10만원 PRO 결합과 PRO 기간 보존은 유지한다.

## 확정 정책

| 현재 유효한 기본 등급 | 신청 | 금액 |
| --- | --- | --- |
| Ultra Pro | AI Brain + 제갈공명 30일 추가·연장 | 50,000원 |
| Pro | AI Brain + 제갈공명 30일 추가·연장 | 50,000원 |
| 무등급 또는 기본 구독 만료 | Pro 30일 | 50,000원 |
| 무등급 또는 기본 구독 만료 | Pro + AI Brain + 제갈공명 | 100,000원 |

AI 이용 중 Pro 잔여기간은 일시정지한다. 신규 결합 신청도 Pro 30일을
보존하고 AI 종료 후 차감한다. Ultra Pro는 무기한 유지한다.
기존 Ultra Pro 신규 구매 옵션은 별도 접힘 영역에 유지한다.

## 구현 계약

- 새 AI 포함 신청은 서버에서 금액을 계산하고 `admin_note`에
  `[ai_bundle_v2]` 정책 마커를 저장한다. 사용자 화면에서는 마커를 숨긴다.
- 승인 트랜잭션은 AI Brain과 제갈공명 권한을 함께 부여한다. 기존의
  유료 잔여기간 중 늦은 만료일부터 30일을 연장하며 중복 승인은 연장하지 않는다.
- 구독 신청 시 화면의 `expected_amount`와 현재 서버 계산이 다르면 409로
  재확인을 요구한다. 추가 구독 승인 직전에도 유효한 기본 등급을 확인한다.
- 기존 독립 `aibain_kongming` 신청 URL은 최신 등급별 금액 안내로 연결한다.
  구형 클라이언트의 직접 신청 API는 409로 차단한다.
- 과거 신청 금액, 이미 승인된 독립 이용권, 기존 승인 대기는 변경하지 않는다.
  과거 요청은 저장된 정책으로 승인한다. 기존 단독 이용권 만료 이후에는 새
  기본 등급 포함 플랜으로 갱신한다.
- 실결제와 기존 회원 계정 변경은 검증에 사용하지 않는다.

  승인 전 기본 구독 변경, 구형 신청 차단, 기존 요청 보존, 금액 변경 재확인.
- 프런트엔드: 회원별 카드·입금 안내·신청·승인 대기·재구독 동선, 전체 Vitest,
  TypeScript/Vite 빌드, ESLint 및 PC/모바일 화면 검사.
- 운영: PR CI 통과 뒤 MiniPC 배포 및 새 프로세스 확인, 공개 API health,
  Pages 배포와 공개 번들/요금 페이지 확인.
