# MarketFlow 애드센스 재심사 준비 조사 및 개선

조사일: 2026-09-15 · 대상: https://bit-man.net · 상태: 로컬 구현·검증, 운영 배포 전

## 결론

기존 사이트에는 가이드 7편, 정책 페이지, 정적 HTML, robots.txt, ads.txt가 이미 있다.
이번에는 광고 요청 범위, 무료 콘텐츠 접근, 잘못된 가입 유도, 공개 글 이미지 오류,
출처·정정 안내, 자동 게시물의 근거 없는 표현을 개선했다.
이 변경은 승인 보장이 아니다. 이후 사용자가 제공한 애드센스 화면에서 승인 상태는 ‘주의 필요’,
상태 세부정보는 **‘가치가 별로 없는 콘텐츠’**, ads.txt 상태는 **‘찾을 수 없음’**으로 확인했다.
화면의 최종 업데이트는 2026-09-04 08:29 KST다. 이 날짜를 ads.txt의 정확한 크롤 시각으로 단정하지 않는다.
일부 화면만 고쳤다고 사이트 전체가 승인 조건을 충족했다고 판단해서는 안 된다.

### 거절 화면 확인 후 우선순위

핵심은 독자가 무료로 읽고 활용할 수 있는 고유한 콘텐츠의 가치다. 정책 페이지·메타태그·광고 제거만으로
‘가치가 별로 없는 콘텐츠’가 해소되었다고 볼 수 없다. 근거 있는 사례·재현 가능한 계산·해석의 한계,
기존 자동 게시글의 관련성·출처 정정을 먼저 확인하고 재심사를 요청해야 한다.
[Google의 재심사 준비 안내](https://support.google.com/adsense/answer/12176698?hl=en)도 충분한 고유 콘텐츠와 사용자 경험을 요구한다.

현재 운영 `https://bit-man.net/ads.txt`는 HTTP 200, `text/plain; charset=utf-8`로
`google.com, pub-4268071335236139, DIRECT, f08c47fec0942fa0`을 반환한다.
계정의 게시자 ID와 최종 일치하는지는 계정 화면에서 확인해야 한다.
‘찾을 수 없음’은 Google이 마지막으로 크롤했을 때 파일을 발견하지 못했다는 상태다.
현재 외부 HTTP 점검 성공이 Google 재수집 완료의 증거는 아니다.
[공식 상태 설명](https://support.google.com/adsense/answer/12170222?hl=en),
[ads.txt 크롤 점검 안내](https://support.google.com/adsense/answer/7679060?hl=en)에 따르면 반영에 며칠,
광고 요청이 적으면 최대 한 달이 걸릴 수 있다. 기존 파일은 유지한다.

위 공식 자료에서 이 사이트에 적용할 수 있는 ‘글 N개’, ‘글자 수 N자’, ‘승인까지 N일’ 같은 보장 기준은 확인하지 않았다.
AI 사용만으로 승인 또는 거절을 단정하지 않는다. 출처와 유용성, 오류·중복·과장 여부를 평가한다.
서비스 소개·문의·편집 원칙은 신뢰와 탐색을 돕기 위한 개선이지, 페이지 이름만 추가하면 통과한다는 의미가 아니다.

## 운영 사이트에서 실제 확인한 내용

- `/`, `/guide`, `/robots.txt`, `/ads.txt`: HTTP 200. 홈과 가이드에는 정적 `seo-content` 본문이 존재한다.
- 운영 공개 API의 게시판 수: 공지 16, 자유 8, 분석 108, 로또 22. 조사 시점 값이며 지속적으로 바뀐다.
- 운영 게시글 226: `[종가베팅] 9/15 오늘의 S급 3종목 + A급 7종목`.
  - 이미지가 `/api/community/uploads/...` 상대 경로로 저장되어 있다.
  - 공개 컴포넌트가 이를 API 도메인으로 바꾸지 않아 `bit-man.net/api/...png`가 **404**였다.
    동일 파일의 `marketflow-api.bit-man.net/api/...png`는 **200 image/png**였다.
  - 뉴스는 제목만 제공하고 원문 링크가 없었다. 일부 제목은 해당 기업과의 관련성을 본문만으로 확인하기 어렵다.
  - 모든 종목에 동일한 손절·목표 문구와 즉시 매도 지시를 제시했다.
  - 원천 시각 확인 없이 ‘장마감’, 특정 AI 모델 검증 통과라고 표시하는 생성 템플릿을 확인했다.
- 전체 게시글의 사실관계·이미지 권리·뉴스 관련성을 전수 검수한 것은 아니다. 게시글 226 원문은 이번에 수정하지 않았다.

## 구현한 변경

1. **심사 준비 상태의 광고 요청 중단**
   - 모든 페이지에 들어가던 AdSense 스크립트 및 가이드·커뮤니티 광고 슬롯 제거.
   - `google-adsense-account` 메타태그와 기존 ads.txt의 게시자 ID 유지.
   - 광고 비활성화는 정책 준수나 콘텐츠 품질의 대체 수단이 아니다.

2. **실제로 읽을 수 있는 무료 콘텐츠**
   - `/guide`, `/guide/:slug`는 미가입·승인 대기·만료 회원 모두 열람 가능.
   - 대시보드 인증 및 유료 권한은 기존 규칙 유지.
   - 홈 상단에 무료 검증 예제 및 전체 가이드 링크.
   - ‘무료로 시작하기’를 ‘무료 계정 만들기’ 등 계정 상태에 맞는 행동으로 변경하고 대시보드의 유료 이용 조건 안내.

3. **교육용 검증 사례 추가**
   - `/guide/signal-verification-worked-example`.
   - 가격 배열에서 계산한 순수익 `7.5%, -4.5%, 1.5%, -0.5%`, 완료 적중률 `50%`, 완료 표본 평균 `1.0%`.
   - 전체 6건 중 완료 4건, 누락 1건, 대기 1건. 실제 실적·추천 종목·현재 시세가 아닌 가상 예제라고 명시.
   - 적중률 분모, 비용, 기준지수 대비 차이, 놓친 후보를 알기 위해 필요한 전체 모집단 설명.

4. **운영 투명성·개인정보 설명**
   - `/editorial`, `/contact`: 운영 주체, AI 활용, 정정, 저작권·개인정보 신고 경로.
   - 정책과 정적 HTML은 같은 데이터 파일 사용.
   - 개인정보 방침에서 광고 관련 정보 수집과 외부 제공 없음의 모순 해소.
   - 실제 운영자의 법적 정보·데이터 처리 현황 전부를 법률 검토한 것은 아니며, 이번 수정은 확인된 광고 고지 범위에 한정한다.

5. **게시글 가독성과 향후 생성 품질**
   - 공개 게시물에도 기존 HTML 정제 및 API 이미지 URL 보정 함수 사용.
   - `scripts/post_daily_analysis.py`는 종목 코드, 원본 가격·등락률, 확인 불가 상태를 표시.
   - 원문 링크가 있는 뉴스만 인용하고 HTML 문자와 URL을 검증.
   - 고정 매매 지시, 근거 없는 장마감 확정·특정 모델 검증 통과 문구 제거.
   - 생성 함수만 테스트했으며 실제 게시·로그인·이미지 생성·스케줄러 실행은 하지 않았다.

6. **정적 문서 검증**
   - 17개 정적 페이지 생성, 새 경로 sitemap 등록, 기사 OG 유형 수정.
   - JS 비활성화 시 중복된 홈 noscript가 각 기사에 붙던 문제 제거.
   - `npm run check:public`: 실제 빌드 산출물의 본문 일치, 소유권 메타, 광고 부재, canonical, sitemap, JSON-LD, 예제 계산 검증.

## 검증

- 프런트엔드 전체: 47개 테스트 파일 / **289개 테스트 통과**.
- Python: `tests/test_daily_analysis_editorial.py`, `tests/test_public_community.py`, `tests/test_signal_contract.py` **14개 통과**.
- `npm run build`: TypeScript·Vite·17개 정적 HTML 생성 통과.
- `npm run check:public`: 17개 페이지 및 예제 계산 통과.
- 인앱 브라우저: 신규 가이드·문의·편집 원칙 확인. 모바일 375px 및 데스크톱 1280px에서 가로 넘침 없음.
- 로컬 브라우저 검증 시에만 `VITE_STATIC_ASSET_ORIGIN=http://127.0.0.1:4173`을 사용한다.
  운영용 최종 빌드는 기본 Pages 자산 주소로 다시 생성했고 로컬 자산 주소가 없음을 확인했다. 배포 명령은 항상 새 빌드를 실행한다.
- 별도 읽기 전용 코드 리뷰: 차단할 만한 신규 문제 없음.
- 기존 테스트 환경의 Canvas 미구현 경고 및 Browserslist 데이터 갱신 알림은 통과 여부에 영향을 주지 않았다.

## 재심사 전 남은 운영 단계

1. **확인된 사유에 대응**: ‘가치가 별로 없는 콘텐츠’를 기준으로 실제 사례·고유 해석·무료 접근·기존 게시글 품질을 점검한다. ads.txt는 현재 정상 응답과 계정의 재수집 상태를 구분한다.
2. **배포**: 프로젝트 지침에 따라 사용자의 배포 요청 후 실행. 프런트 배포와 자동 게시 스크립트가 실행되는 호스트 반영은 별개다.
3. **운영 검증**: 새 경로·기사의 200 응답 및 본문, 이미지, ads.txt, 소유권 메타를 확인한다.
   JavaScript 로딩 후에도 같은 콘텐츠가 보이는지, 모바일 메뉴·문의 링크가 동작하는지 확인한다.
4. **기존 게시물 정정**: 226번을 포함한 기존 자동 게시물은 새 템플릿 배포만으로 바뀌지 않는다.
   원자료 대조 후 뉴스 관련성·시각·모델 사용·매매 지시를 정정해야 한다. 원문 근거 없이 수치를 새로 만들어 고치지 않는다.
5. **동의 및 광고 설정**: 애드센스 계정에서 사이트 상태와 소유권 확인 방식을 확인한다.
   승인 후 광고 활성화 시 인증 CMP, 광고 파트너 공개, 자동 광고 제외 페이지를 별도 검증한다.
   메타태그 확인 방식으로 변경이 필요한지는 계정 화면에서 확인해야 한다.
6. **Google에 재심사 요청**: 운영 반영과 기존 콘텐츠 정리 이후 진행. 테스트 성공이나 정적 페이지 수만을 재신청 근거로 삼지 않는다.

커밋·푸시·배포·기존 운영 글 수정·애드센스 계정 설정 변경·재심사 신청은 이 작업에서 수행하지 않았다.
