# 구독 신청 화면 가독성 개선

기존 React/Vite와 어두운 서비스 디자인을 유지하고, 모바일 회원의 다음 행동을 분명하게 한다.

- 공통 단계: 플랜 선택 → 입금·신청 → 승인 대기. 현재 단계와 완료 단계를 구분한다.
- 신규·만료 회원: PRO 5만 원 / PRO + AI 브레인·제갈공명 10만 원을 먼저 비교한다.
- 기존 PRO·Ultra PRO: 현재 이용권은 별도 표시하고 AI 묶음 추가 5만 원을 안내한다. PRO만 30일 연장하는 경로도 제공한다.
- 가격은 월 자동결제처럼 보이지 않도록 이번 입금 금액으로 표시한다.
- PRO 기간 보존은 “AI 이용 중 줄어들지 않고 종료 후 다시 시작”으로 설명한다.
- 입금: 선택 금액 → 은행·계좌 복사 → 실제 입금자명 → 입금했어요·승인 신청 순서.
- 계좌 복사는 성공/실패를 안내하고 실패 시 계좌를 직접 선택할 수 있다.
- 대기: 실제 접수 금액·입금자명·신청 서비스를 표시한다. 중복 입금 금지 안내를 먼저 보여주고 계좌 정보는 접어 둔다.
- 취소·거절: 처리 사유와 재신청을 제공하며, 이미 입금한 경우 먼저 문의하도록 안내한다.
- 기존 승인 자동 확인, 접근권한, 서버 가격 검증, 관리자 권한은 유지한다.
- 기존 회원이 입금 화면에서 다른 플랜을 선택하면 변경 모드로 돌아간다.
- 만료 안내 팝업과 배너 모두 플랜 비교로 연결한다.

검증: Vitest 전체 1,291개, ESLint, TypeScript/Vite 빌드, 320/390/1440px Chrome.
신규·만료·PRO·Ultra PRO 각각 플랜 선택부터 승인 대기까지 검사한다.
브라우저 신청은 합성 API 응답을 사용하며 실제 회원 신청·결제는 생성하지 않는다.
