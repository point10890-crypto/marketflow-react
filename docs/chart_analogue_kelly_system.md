# 차트 유사 사례와 켈리를 연결한 우량주 연구 시스템

AI Brain의 `/dashboard/ai-bain/chart-predict`에서 현재 시총 상위 우량주를 검사하고, 근거가 있는 관찰 후보를 최대 3개 보여준다. 기존 차트 조회·종목명 검색·TOP3·구독 접근권한은 유지한다. 이 버전은 **연구·관찰 시스템**이며 주문 시스템이나 승률 인증 서비스가 아니다.

## 사용 순서

1. 검사 범위와 자료 기준일을 확인한다. TOP100에서 현재 재무 기준을 통과한 종목만 대상·참조 사례로 사용한다.
2. 후보 이름과 코드, 표본 상태를 본다. `자료·표본 부족`은 투자 조건 통과가 아니다. 후보가 3개 미만이면 없는 종목을 채우지 않는다.
3. 차트의 실선은 현재252관측일, 점선은 닮은 과거 구간이다. 마지막 가격을100으로 환산했다. 음영은 **그 과거 종목에서 이미 일어난 결과**다. 현재 종목의 미래 경로가 아니다.
4. 과거 사례 기준일 다음 관측 종가에 진입해20개 추가 관측 종가 후 청산한다. 순수익은 `(청산가/진입가 - 1) - 0.0033`; 왕복 비용·슬리피지33bp를 가정한다. 실제 체결 비용은 아니다.
5. 시간순 훈련·검증 표본, 순수익 상승 빈도, Wilson 하한, 손익비와 평균 순수익을 함께 본다. 1~3개 사례의100% 상승 빈도를 미래 승률100%로 읽지 않는다.
6. 조건 통과 시 표시되는 켈리 비중도 연구 시나리오다. 승인 비중은 현재 보류이며 자산 입력은 화면 계산만 변경한다.

## 계산과 한계

현재 관측 세션 달력의60% 날짜를 사전에 고정해 분리한다. 훈련 결과가 경계 이전에 끝나고 검증의252일 입력 구간이 경계 이후에 시작해야 한다. 동일 종목의 전체 입력·결과 구간 중복을 제거한다. 같은 시장 국면을 공유하는 다른 종목은 독립 표본이 아니므로 Wilson 하한은 가정에 따른 진단이다.

각 구간에30개 이상, 비용 후 상승 빈도60% 이상, Wilson95% 하한60% 이상, 손익비1 이상, 평균 순수익 양수를 모두 요구한다. 손실 표본이 없으면 손익비는 미산정이다. 오늘 수집된 수정주가와 현재 생존한 우량주를 사용하므로 최초 가격·공시 판본과 역사적 유니버스를 재현한 walk-forward 성과가 아니다. 별도2σ 전략의 승률을 이 전략의 승률로 재사용하지 않는다.

참고 점수는 비용 후 평균 수익률에 비용 후P10 수익률의 절반을 더한 고정 식이다. 검증 표본이 없으면 훈련 표본을 사용하며 표본 부족 상태를 유지한다. 양수 점수만 관찰 후보에 들어간다. P10은20일 말 수익률이지 기간 중 최대 낙폭이 아니다. 이 순위에는 거래량·실시간 수급·공시 촉매를 직접 반영하지 않는다.

충분한 검증 수익률이 있을 때 `mean(log(1+fR))`를 최대화하는 경험적 켈리f를 구한다. 하프켈리0.5→종목한도20%→최근 일별 변동성3% 초과 시 추가절반→총노출60%/현금40% 제한을 적용한다. 단순 승률60%·손익비1의 이항 켈리20%를 실제 주가 수익률에 그대로 할당하지 않는다. 켈리는 손실이나 파산 위험을 없애는 보장이 아니다.

## 운영

라이브 API/LLM 없이 이미 준비한 가격 색인과 날짜·출처가 있는 TOP100/재무 검사JSON을 사용한다.

```powershell
.\.venv\Scripts\python.exe scripts\scan_chart_analogue_kelly.py `
  --universe data\kelly_research\large_cap_20261001_v2\report.json `
  --index-root data\chart_analogue `
  --root data\chart_analogue\kelly
```

`--universe`는 최초 설치나 신규 범위 준비 시 지정한다. 날짜를 단순히 덮어써 갱신한 것으로 처리하면 안 된다. `scripts/screen_large_cap_kelly.py`의 기존 수집·재무 검사로 새 기준일의 실제 범위를 준비해 넘긴다. canonical `universe.json`이 저장되면 이후 고정 검사에서 재사용한다. 가격과 범위가7일을 초과하면 보류하며 과거 순위를 현재 결과처럼 표시하지 않는다. 과거 cutoff의 CLI 분석은 신규 전향 결정을 만들지 않는다.

기존 `scripts/refresh_chart_analogue_index.ps1`은 가격 수집→색인→기존평가→기존TOP3 이후, 준비된 canonical universe가 있으면 새 검사를 실행한다. 스크립트가 연결된 기존 운영 작업에서 동작한다. 이번 소스 구현만으로 새 운영 스케줄을 설치하거나 원격 서버를 배포한 것은 아니다. CLI exit0은 연구 보고서 저장, exit2는 자료/범위 보류, exit1은 실행 실패다.

API GET/POST `/api/admin/mirofish/chart-analogue/kelly`는 기존 관리자·활성AI Brain 권한을 요구한다. GET은 저장 상태만 읽는다. POST는 고정 정책의 단일 백그라운드 작업을 시작한다. 옵션 임의 변경은 허용하지 않는다. 보고서는 private/no-store다.

`report.json`은 현재 공개 연구 결과, `runs/`는 원본 사례 감사 근거, `decisions.json`은 실제 한국시간 날짜별 첫 결정, `observations.json`은 이후 성과다. 첫 결정은 같은 날 재검사·실패 복구로 바뀌지 않는다. 미래 자료 갱신 시 기존 `observed_outcomes`가 실제 다음 종가 진입·20일 청산 결과를 관측하며33bp를 차감한다. 미성숙 결과는0% 손실로 바꾸지 않는다. 동일 시장/기간의 관측은 독립 검증으로 인증하지 않으며 자동 투자 승인을 열지 않는다. journal은730결정일로 제한하며 초과 시 명시적으로 아카이브가 필요하다.

파일 잠금과 원자적JSON 저장으로 중복 실행을 막고, 같은 출처·범위·현재 날짜 결과를 재사용한다. 범위 해시나 색인 판본이 달라지면 다시 검사한다. 데이터·근거와 인증정보는 커밋하지 않는다.
