## 범위와 결정

- 기존 AlphaLab·제갈공명 후보/가격계획/승인 계약은 유지한다. 새 리그는 별도 원장과 연구 채점 계층이다.
- Ruling: 과거 사용자 요청인 시총 상위 우량주 범위를 우선한다. 초기 전종목 약 2,900개 신규 수집 대신 기존 검증된 AlphaLab 일봉 코호트를 재사용한다. 기저율은 해당 코호트의 과거 추정치이고 시장 전체나 독립 표본 외 성과가 아니다.
- Ruling: 원장·미래 정보 차단·원문 증거·잡 의존성·동시 실행을 먼저 검증한다. 완료한 수집과 원장은 재시도 시 보존한다.
- Ruling: 11월 12일 4종목의 15:32 마감 VI 문제를 리그 수집에 그대로 들여오지 않는다. VI 원문과 분봉을 대조하는 별도 소스 버전을 사용하며 기존 AlphaLab의 봉인된 v1 계약은 재작성하지 않는다.
- Ruling: 이미 승인된 테스트·푸시·배포 범위에서 진행한다. 실주문·결제·신규 유료 API·새 운영 알림은 추가하지 않는다. 기존 PR 문서의 반복 승인 단계는 새 승인을 요구하는 근거로 해석하지 않는다.
- 첫 전향 예측과 충분히 성숙한 성과를 구분한다. 배포 당일 실성과를 만들기 위한 과거 예측 소급 제출은 하지 않는다.

## 구현 보완

- `resolved_at` 이전에 알려진 공식 결과만 환산하며, 미래 void가 과거 코호트를 닫지 않는다.
- 기저율은 거래소 달력상 연속 8거래일 자료가 있어야 집계한다. 가격 이벤트 경고·거래 불가 일봉은 제외한다.
- 기준선은 같은 종목·이벤트·실제 진입일·일치한 outcome끼리 비교한다.
- 기준선 버전 `2-sealed-quality`: 기존 봉인된 재무 우량 TOP100 부분집합의 전 종목에 두 기준선을 제출한다. 종가베팅 파일만의 후보 범위에서 변경했다. 새 시장 전종목 네트워크 수집은 기본 경로에서 제거했다.
- 봉인 입력 전체를 캡슐로 복사하고 현재 구성 종목 선택 편향을 명시한다. `asof_ts`는 가격 기준 세션의 종가 시각이며, 실제 정보 취득 시각은 별도 `information_cutoff`/종목별 `capture_audit`에 보존한다. 예측 생성은 서버 시각이며 진입 장 시작 이후 제출은 기권 처리한다.
- 전체 분봉·VI 공개 원문을 저장하고 저장 전에 무통신 재현을 통과해야 채점용 봉이 된다. 새 리그 전용 `league-kis-regular-vi-v2`이며 기존 AlphaLab 소스 계약과 과거 결정은 변경하지 않았다.
- E1의 방향 결과는 동일하다. 최초 운영 전 손절 갭 모형을 보수화했다: 시가가 손절 아래면 실제 시가로 손실을 계산한다. 비용은 현재 공통 왕복 비용 설정을 사용한다. 체결 보장 또는 실거래 성과가 아니다.
- 워커 전체 파일 잠금과 원자적 작업 선점으로 동시 실행을 막는다. 중단 후 남은 시도 횟수만 사용한다.
- 아침 제출은 입력 동기화 성공을 기다린다. 저녁 해소는 수집의 성공 또는 최종 재시도 종료를 기다린 뒤 정상 봉만 처리한다. 일부 영구 누락이 다른 종목 해소를 막지 않으며 누락 건은 보류/20세션 이후 void 정책을 따른다.
- CLI에서 프로젝트 환경을 로드하되 출력하지 않는다. 새 리그 텔레그램 알림은 기본 비활성이다.
